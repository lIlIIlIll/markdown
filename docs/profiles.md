# Profiles

- `commonmark-0.31.2`: exact CommonMark 0.31.2.
- `gfm-0.29`: exact GFM 0.29-gfm, including extension sections and tagfilter.
- `gfm-modern-v1`: CommonMark 0.31.2 with tables, task items, strikethrough, extended autolinks, and tagfilter.
- custom: explicit base profile plus compiled extensions.

`commonMark()` is fixed to 0.31.2 for 1.x; `gfm()` is fixed to `gfm-modern-v1`. New standard semantics require a new profile ID.
